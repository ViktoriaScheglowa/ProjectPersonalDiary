# LifeCanvas - Личный дневник и трекер развития
Веб-приложение для ведения личного дневника с комплексным подходом к саморазвитию, включающее управление моментами, привычками, целями и мыслями.

## Описание
LifeCanvas - это многофункциональная платформа для личного развития, которая объединяет в себе дневник, трекер привычек, планировщик целей и блокнот для идей. Приложение помогает систематизировать личный рост и сделать самосовершенствование регулярной практикой.

### Основные модули

#### 📝 **Моменты**
- Запись значимых событий и впечатлений
- Прикрепление фотографий и медиафайлов
- Приватность или публичный доступ к моментам

#### 🔄 **Привычки**
- Создание и отслеживание ежедневных привычек
- Напоминания о необходимости выполнения
- Визуализация прогресса и статистики
- Анализ последовательности выполнения

#### 🎯 **Цели**
- Постановка краткосрочных и долгосрочных целей
- Отслеживание прогресса выполнения
- Публичные шаблоны целей для вдохновения

#### 💭 **Мысли и идеи**
- Быстрая запись мыслей и идей
- Организация записей по категориям
- Поиск и фильтрация записей
- Экспорт мыслей в различные форматы

### Ключевые особенности

- 🔒 **Конфиденциальность** - Полный контроль над доступом к вашим данным
- 📊 **Аналитика** - Детальная статистика и визуализация прогресса
- 🔔 **Напоминания** - Уведомления о привычках и задачах
- 🌐 **Сообщество** - Возможность делиться публичными моментами и целями
- 📱 **Адаптивность** - Удобный интерфейс на всех устройствах

## Установка

### Предварительные требования

- Python 3.11+
- PostgreSQL 13+
- Docker и Docker Compose (рекомендуется)

### Быстрый запуск с Docker

1. **Клонируйте репозиторий**
git clone https://github.com/ViktoriaScheglowa/ProjectPersonalDiary.git
cd ProjectPersonalDiary 

2. Запустите приложение
docker-compose up -d --build

3. Настройте базу данных
docker-compose exec web python manage.py migrate
docker-compose exec web python manage.py createsuperuser

4. Приложение доступно по адресу: http://localhost:8000

Локальная установка

1. Создайте виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/MacOS
venv\Scripts\activate     # Windows

2. Установите зависимости
pip install -r requirements.txt

3. Настройте окружение
cp .env.example .env
# Отредактируйте .env файл с вашими настройками

4. Запустите миграции и сервер
python manage.py migrate
python manage.py runserver

Технологический стек

База данных: PostgreSQL
Аутентификация: JWT + сессии Django
Кэширование: Redis
Очереди задач: Celery
Контейнеризация: Docker, Docker Compose
CI/CD: GitHub Actions
